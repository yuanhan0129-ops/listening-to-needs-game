# 素材挑選紀錄

## 遊戲視覺方向

- 成人向、寫實但柔和、簡約扁平。
- 對話卡片以 Phaser 幾何圖形繪製，使用暖白、鼠尾草綠、灰藍和柔和陶土色。
- 角色以專案自製的 SVG 肖像呈現；使用系統字體，不加外部音效或背景音樂到 MVP。

## Kenney UI Pack

- 官方來源頁：<https://kenney.nl/assets/ui-pack>
- 官方直接下載：<https://kenney.nl/media/pages/assets/ui-pack/f651646eab-1718203990/kenney_ui-pack.zip>
- 授權：同包 `License.txt` 標示 Creative Commons Zero（CC0）。
- 檔案、尺寸與來源中繼資料：見 `ui-pack.manifest.json` 和 `ui-pack.download.json`。
- 視覺檢視後，這個素材包的鮮明色塊、立體邊框與陰影和本遊戲的柔和扁平方向不一致，因此保留在專案供日後參考，MVP 不載入其按鈕或面板素材。

## MVP 實際素材

- `public/assets/images/characters/yu-an.svg`：本專案自製的角色肖像。
- 對話面板、選項卡與按鈕：使用 Phaser 幾何圖形繪製，不依賴外部 UI 圖片。
- 字體：系統 sans-serif 字體堆疊。
